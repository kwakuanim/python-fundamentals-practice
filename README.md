# python-fundamentals-practice
Beginner Python exercises covering control flow, loops, functions, strings, and file handling.
# Python Fundamentals Practice

This repository documents my progress while learning Python for data science and scientific data analysis.

## Exercises

### `control_flow.py`

Uses `if`, `elif`, and `else` statements to classify student scores into grades and validate the input range.

### `loops.py`

Uses a `while` loop to collect numbers and calculate their total until the user enters a negative number.

### `functions.py`

Defines and calls a function that calculates the average of a list of student scores.

## Concepts practised

- Variables and numerical data types
- User input
- Conditional statements
- `while` loops
- Lists
- Functions
- Built-in functions such as `sum()` and `len()`
- Formatted strings

## Running the exercises

1. Clone this repository.
2. Open the project in PyCharm or another Python editor.
3. Run any Python file individually.

No external packages are required for the current exercises.
